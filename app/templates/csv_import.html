Export as CSV — every broker offers it, and it reads far more reliably than a PDF. Nothing is saved until you've checked the columns on the next screen, and the file itself is never stored.

What it needs

  • A name for each holding — scheme, stock, security, whatever your broker calls it.
  • A value — either a value column, or a quantity and a price we can multiply.
  • An ISIN, if you have one. Optional, but it's what lets us price the holding live and file it in the right category by itself.

Headers don't need to match anything. "Cur. val", "Market Value" and "Current Value (INR)" are all understood, and anything we get wrong you can correct on the next screen.
